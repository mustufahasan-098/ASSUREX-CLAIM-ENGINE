Dataset Generation Walkthrough
The 1,500-claim dataset is generated by dataset_generator/generate_dataset.py:

python -m dataset_generator.generate_dataset
Process
17 scenario archetypes (5 valid, 5 invalid, 7 review) generate claims with realistic field combinations
Self-test: every claim is evaluated by the actual rule engine (src/rules.py) BEFORE being written — the generator refuses to proceed if any label disagrees (1500/1500 check)
Stratified split: 70/15/15 (1050/225/225) per class, split BEFORE image generation
Claim Summary Cards: python -m card_generator.generate_cards renders train (2 variations = 2,100 images), val (225), test (225)
Key design decisions
The scenario column is STRIPPED from CSVs to prevent label leakage
All variations of one claim stay in the same split (no leakage in either CSV or image form)
Fixed seed (42) — fully reproducible
